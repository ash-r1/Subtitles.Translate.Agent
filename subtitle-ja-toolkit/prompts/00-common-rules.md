# 全工程共通規約（00-common-rules）

この規約は `prompts/01`〜`10` のすべての工程に適用する。各工程プロンプトは
この規約を前提として書かれており、矛盾する場合は各工程プロンプト側が優先する。

## 1. 出力の機械可読性

- 出力は指定されたスキーマの **生の JSON**（または明示された場合のみ YAML）とする。
- ファイルへ書き出す場合、Markdown フェンス（```）を**付けない**。
- 説明文・前置き・後書きを JSON の外に付けない。
- 件数を固定値で書かない。入力件数は常に `{{batch_item_count}}` を参照し、
  出力配列の要素数はそれと一致させる。
- `id` は**文字列型**で保持し、入力の順序を変えない。ID を改番しない。
- `original`（原文）フィールドは入力から**一字も変えずに**エコーする。
- timecode は入力形式（`HH:MM:SS,mmm` 等）を保持する。

## 2. null / 空文字 / 空配列 / unknown の使い分け

| 値 | 意味 |
|---|---|
| `null` | 「該当なし・変更なし」（例: 修正不要の `revised_text`） |
| `""` | 使わない（意図的な空文字列が仕様のフィールドを除く） |
| `[]` | 「検査したが 0 件だった」 |
| `"unknown"` | 「検査したが判定できなかった」（話者・性別など列挙値フィールド用） |
| `"not_observed"` | 「字幕中に証拠がなく、記述しない」（感情別スタイルなど） |

不明な値を捏造しない。判定できないものは `unknown` / `null` とし、必要なら
`unresolved_questions` に理由を残す。

## 3. confidence の尺度（全工程統一）

- `"high"`: 字幕中に直接の証拠がある（名指し・自己言及・明示的な応答）
- `"medium"`: 複数の間接証拠から合理的に推定できる
- `"low"`: 状況からの推測。代替候補がありうる

`low` の推定を後続工程で事実として扱ってはならない。`low` の項目は必ず
`unresolved_questions` または `unresolved-items.yaml` に転記する。

## 4. evidence ID の形式（全工程統一）

- 単一字幕: `"sub:42"`（字幕 ID を文字列で）
- 範囲: `"sub:42-45"`
- 根拠は配列 `evidence_ids: ["sub:42", "sub:118-120"]` で持つ。
- 根拠が示せない主張は書かない（confidence を下げるか unresolved に回す）。

## 5. 思考過程の扱い

- 内部の推論・思考過程を出力に含めない。開示するのは**判断結果**と、
  1〜2 文の短い根拠（`critique` / `reason` / `note`）、`confidence`、
  `evidence_ids` のみ。

## 6. 原文と ID の不可侵

- 元字幕のテキスト・ID・timecode を変更する工程は存在しない
  （Step 9 のみ、出力ファイル側の timecode と改行を変更できる）。
- 訳文フィールド以外に翻訳文以外の情報（注釈・タグ）を混ぜない。

## 7. 日本語共通原則（翻訳系工程 5〜8 に適用)

1. 英語の `I` / `you` / `he` / `she` / `it` / `they` を機械的に表面化しない。
   日本語はゼロ代名詞が基本。省略 → 名前/役職 → 明示代名詞の順で検討する。
2. `you` の訳を「あなた」に既定しない。判断順:
   ① 省略できるか → ② 名前/役職で呼ぶか → ③ 文脈補完が要るか →
   ④ 明示が必要か → ⑤ 関係に合う語（君/お前/あんた/そちら…）は何か。
3. gender だけを根拠に一人称・語尾・語彙を決めない。
4. 原文にない役割語（「〜だわ」「〜かしら」「〜じゃ」「〜ぞ」等）を、
   人物像の分かりやすさのために付与しない。character profile に根拠付きで
   定義されている場合のみ使用できる。
5. 意味単位は字幕行をまたぐ。行単位で訳す前に必ず文全体を復元する。
   ただし後続字幕の内容語（名詞・動詞）を現在行へ先取りしない。
6. 句読点・記号は原文を写さず、`{{global_style_guide}}` の
   `orthography`（表記方針）に従う。

## 8. 入力変数が欠けている場合の共通フォールバック

- `{{speaker_map}}` がない → 字幕本文から話者を推定し、必ず confidence を付ける
- `{{character_profiles}}` がない → 中立的で誇張のない訳を優先する
  （一人称は文脈上必要な場合のみ「私」、語尾は標準的な常体/丁寧体）
- `{{glossary}}` がない → 訳語は暫定訳として `provisional` を付けて記録する
- `{{scene_context}}` がない → 場面についての断定的な補完をしない
- `{{subtitle_constraints}}` がない → 文字数・CPS の数値判定を行わず、
  明らかな超過のみ `review_flags` で指摘する
